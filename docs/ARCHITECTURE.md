# Architecture and maintenance

`apps/web/src` contains the Vietnamese React UI, route pages, query client access, a small Zustand toast store, and accessible Radix/shadcn-style UI primitives. React Hook Form and Zod handle account forms. Tailwind v4 is available alongside the app's semantic CSS; Recharts draws activity data and Motion animates the initial dashboard transition.

`apps/api/src` contains the Express app, session authentication, ownership checks, learning endpoints, dictionary queries, and the translation agent. `packages/shared` contains original lesson content and the review scheduler. `prisma` owns the schema, SQL migrations, and repeatable seed. `scripts` contains download/import/translation commands.

Authentication uses bcrypt (cost 12) and 32-byte random session tokens. Only a SHA-256 hash of each token is stored. Cookies are HTTP-only, SameSite=Lax, and Secure in production. State-changing requests with an Origin header must match APP_ORIGINS. Sensitive endpoints are rate limited. All learner records are scoped to the authenticated user. The seeded local demo account is an administrator so it can view import statistics; normal registrations are not administrators. The API binds to loopback. For Internet hosting, configure HTTPS, production cookies, allowed origins, account provisioning, session cleanup and deployment-specific proxy settings first.

The review scheduler is a documented SM-2 variant: ratings map to qualities 0, 3, 4, 5; forgotten cards return after 10 minutes; first and second successful reviews use 1 and 6 days; later intervals use the updated ease factor (floor 1.3), with 0.7/1.0/1.3 multipliers for hard/good/easy. Review history and card scheduling updates are persisted together. Test runs store a server-side question snapshot, never expose keys before submission, calculate scores on the server and allow submission once.

Dictionary entries retain their complete source JSON plus normalized forms, readings, senses and glosses. Stable IDs are the JMdict entry ID plus sense/gloss positions. Reading restrictions and all sense metadata are preserved. Changed gloss/context hashes invalidate translations; reviewed values remain stored and are not overwritten by the agent. Source revisions that reorder senses may require manual review of stale values. Official `jmdict-simplified` combines original priority markers into `common`; unavailable original XML priority values are not invented.

FTS5 `unicode61` indexes English and Vietnamese; a trigram index supports longer partial strings; a small indexed Japanese one/two-character token table supports short partial matches. Indexed normalized forms provide exact/prefix matches, with WanaKana for reliable romaji/kana handling. Search ranks spelling, reading, normalized form, prefix, Vietnamese and partial matches, then commonness. Full words never ship in the frontend bundle. Imports stream the JSON and write 250 entries per transaction using Node's SQLite API against the Prisma-managed schema. Ordinary API reads/writes use Prisma. WAL mode allows reads during imports; avoid concurrent import processes.

AI translation is an offline, explicitly budgeted service. Gemini credentials and model configuration remain server-side. The agent validates the exact ID set, stores each successful result, reuses compatible cached content, records failures, retries with backoff, and resumes by querying untranslated data. A provider interface allows deterministic mock testing. The budget is a hard maximum number of glossary items per invocation, not a currency estimate. Missing credentials never affect normal dictionary search.

Known content boundaries: eight N5 lessons; no N4–N1 curriculum yet. Only selected Vietnamese dictionary glosses are bundled. PDF import extracts selectable text into a review list and does not perform OCR. Drawing is self-assessed, with no stroke-order or accuracy claims. The UI's simple matching exercises ask learners to match one word to one meaning; there is no timed multi-pair matching board. Grammar data uses JSON columns for original lesson examples and exercises; dictionary senses/glosses are relational. Assessment definitions are versioned in shared source and copied into database TestRun records.
